# 周四验收任务清单（先闭环，再 ESP32）

## 1. 顺序

只有一个 MPU6050，所以按这个顺序做：

```
第一阶段：MPU6050 留在车上 → 把 yaw 闭环调通
第二阶段：拆 MPU6050 到手柄 → 做 ESP32 体感遥控
第三阶段：周四彩排，决定最终演示哪一个
```

**注意：一个模块不能同时装在车和手柄上。**

- 第一阶段验收：`Y90` 能转到 90° 附近并保持；
- 第二阶段验收：手柄倾斜能控制前进/后退/转向；
- 周四演示只能二选一，建议以**闭环**为主，ESP32 作为加分项。

---

## 2. 第一阶段：车端 yaw 闭环

### 2.1 目标

1. `Y90` 后车转到 90° 附近，误差 ≤ 5°；
2. 到位后能保持，被轻推能修回；
3. 不绕圈、不持续正反馈；
4. 5 s 没到位会停车；
5. 手动指令/掉线能立即打断。

### 2.2 当前配置

```c
#define IMU_YAW_SIGN           (-1.0f)  // 顺时针为正，和网页一致
#define HEADING_OUTPUT_SIGN    (-1.0f)  // 实测反向
```

这两个符号必须配合正确，否则会绕圈。

### 2.3 测试步骤

1. 烧当前固件；
2. 上电后车静止 1 秒，等 MPU6050 校准；
3. 确认 `g_imu_status == 0`，yaw 静止时不漂；
4. 发 `Y90`；
5. 记录：
   - 车往左还是往右转；
   - 网页 YAW 增大还是减小；
   - 到 90° 是停住、冲过头，还是绕圈。

### 2.4 现象与处理

| 现象 | 处理 |
|---|---|
| 车往左转，YAW 增大 | `HEADING_OUTPUT_SIGN` 改 `+1.0f` |
| 车往右转，YAW 减小 | `IMU_YAW_SIGN` 改 `+1.0f` |
| 方向对，冲过头 | `KP` 调小，`KD` 调大 |
| 方向对，最后几度转不动 | `MIN_RPM` 调大 |
| 绕很多圈 | 先查方向符号，不要调 PID |
| 静止时 yaw 一直漂 | 重新校准，检查 MPU 固定 |

### 2.5 验收

- [ ] `Y90` 到 90±5°；
- [ ] 保持 10 秒不漂走；
- [ ] 轻推后能修回；
- [ ] `Y180` 正常；
- [ ] 5 s 超时停车；
- [ ] 手动指令/掉线立即停。

## 3. 第二阶段：ESP32 体感手柄

### 3.1 架构

```
手持 ESP32 + MPU6050
        │ Wi-Fi UDP： "L,R\n"
        ▼
电脑 Python 桥（蓝牙 COM14）
        ▼
车上 JDY-31 → STM32（只做手动轮速）
```

### 3.2 接线

| MPU6050 | ESP32-S3 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SDA | GPIO8 |
| SCL | GPIO9 |

### 3.3 映射

- 前后倾 → `throttle`；
- 左右倾 → `steer`；
- 死区 ±5°；
- `L = throttle + steer`，`R = throttle - steer`；
- 超 ±100 整体缩放；
- 回正发 `0,0`。

### 3.4 验收

- [ ] 前倾前进、后倾后退；
- [ ] 左右倾转向；
- [ ] 回正停车；
- [ ] 丢包/关手柄 300 ms 内停。

## 5. 周四验收标准

### 闭环（优先）

1. `Y90` 到 90±5°；
2. 保持不漂走；
3. 轻推能修回；
4. 5 s 超时停车；
5. 手动/掉线立即停。

### ESP32 手柄（加分）

1. 前倾前进、后倾后退；
2. 左右倾转向；
3. 回正停车；
4. 断信号 300 ms 内停。

---

## 6. 风险

| 风险 | 处理 |
|---|---|
| 一个 MPU 不能同时装两边 | 先闭环，再拆给手柄；周四二选一 |
| 方向符号错 | 只改 `IMU_YAW_SIGN` 或 `HEADING_OUTPUT_SIGN` |
| 绕圈 | 先查符号，别调 PID |
| 电脑必须开着（第二阶段） | 检查电量、睡眠、蓝牙 COM14 |
| ESP32 桥没调通 | 兜底用现有 `手柄/control_car.py` 蓝牙控制 |
