# 周四验收任务清单（2026-11-12 晚）

## 1. 最终目标

电脑或手机浏览器打开 ESP32-S3 的网页，能够：

1. 控制小车前进、后退、左转、右转、停车；
2. 实时看到小车 yaw、左右轮目标/实测转速；
3. 设定目标航向（旋钮或输入框），小车闭环转到目标角并保持；
4. 松手、停车、断网、关页面时，小车能自动停。

一句话验收：

> 浏览器点一下，车能按预期动；转 90° 能停在 90° 附近；网络断了车会停。

---

## 2. 架构决定（周四前不要改）

采用 **ESP32 做网页 + 串口桥，STM32 继续管电机和陀螺仪**：

```
手机/电脑浏览器
      │ Wi-Fi
      ▼
ESP32-S3（WebServer）
      │ UART 9600，文本协议
      ▼
STM32 USART3
      │ MPU6050 yaw + 编码器 + PID
      ▼
TB6612 → 左右电机
```

原因：

- STM32 已经接了 MPU6050、编码器、TB6612，航向闭环也写好了；
- ESP32 再读一个陀螺仪不会让控制更好，只会多一层延迟和一套标定；
- 周四前时间只够把“网页 → ESP32 → STM32”这条链路打通；
- 以后想用 ESP32 读陀螺仪，可以作为第二阶段，不影响现在验收。

**默认方案：STM32 的 MPU6050 负责 yaw，ESP32 只负责网页和转发。**

## 3. 硬件接线

### 3.1 ESP32 ↔ STM32

| ESP32-S3 | STM32F103 | 说明 |
|---|---|---|
| GPIO17 (TX1) | PB11 (USART3_RX) | ESP32 发命令给 STM32 |
| GPIO18 (RX1) | PB10 (USART3_TX) | STM32 发遥测给 ESP32 |
| GND | GND | 必须共地 |

- 拔掉原来的 JDY-31 蓝牙模块，USART3 改接 ESP32；
- 两边都是 3.3 V 逻辑，不需要电平转换；
- ESP32 用 USB 或独立 5 V 降压供电，**不要**从 STM32 的 3.3 V 取电（Wi-Fi 瞬时电流大）；
- 先只接 TX/RX/GND，不要接电机，确认串口通再上车。

### 3.2 供电

- 调试：ESP32 插 USB，STM32 用 ST-Link/USB 供电；
- 装车：电池 → 5 V 降压 → ESP32 5V；电池 → TB6612 VM；共地；
- 如果 ESP32 反复重启，先查 5 V 供电和电容。

## 4. 通信协议

### 4.1 ESP32 → STM32（沿用现有文本协议）

```
F60\n      前进 60%
B60\n      后退 60%
L70\n      原地左转 70%
R70\n      原地右转 70%
S\n        停车
Y90\n      转到 90° 航向并锁定
```

### 4.2 STM32 → ESP32（沿用现有遥测）

5 Hz，一行 5 个数：

```
目标L*10 目标R*10 实测L*10 实测R*10 yaw\n
```

例如：

```
1500 490 1480 495 23
```

表示左目标 150 rpm、右目标 49 rpm、左实测 148 rpm、右实测 49.5 rpm、yaw 23°。

### 4.3 浏览器 ↔ ESP32

建议先用 **HTTP 轮询**，不引入 WebSocket，降低风险：

```
GET /            -> 网页
GET /cmd?c=F60   -> 转发 F60 给 STM32
GET /data        -> 返回 JSON：{"yaw":23,"tl":150,"tr":49,"ml":148,"mr":49}
```

网页每 100 ms 请求一次 `/data`，按钮/摇杆变化时请求 `/cmd`。

## 7. 验收标准

必须全部满足：

1. 浏览器打开 ESP32 IP，页面正常显示；
2. `F/B/S` 按钮控制前进、后退、停车，响应 < 300 ms；
3. `Y90` 后车转到 90° 附近，误差 ≤ 5°，并能保持；
4. 页面 yaw 数值与车实际转向一致；
5. 松手/停车/断网/关页面，车自动停；
6. 连续运行 5 分钟，不重启、不失控、不堵转；
7. 手机热点或同一 Wi-Fi 下可复现。

## 8. 风险与兜底

| 风险 | 处理 |
|---|---|
| yaw 方向反 | 改 `IMU_YAW_SIGN` 或 `HEADING_OUTPUT_SIGN`，只改一个 |
| yaw 漂移 | 上电摆正、静止 1 s 校准；演示前重新上电 |
| Wi-Fi 延迟/丢包 | 用手机热点，ESP32 靠近电脑；命令 200 ms 重发 |
| 串口不通 | 先共地，TX/RX 交叉；用 `S` 命令测试 |
| ESP32 重启 | 独立 5 V 供电，加电容，不接电机电源 |
| 周四前 ESP32 桥没通 | 兜底：笔记本 USB + 现有 Web Serial 网页，先保证能演示 |
| 航向闭环不稳 | 降 `MAX_RPM`，先 40~60 rpm；不行就只做手动 + yaw 显示 |
